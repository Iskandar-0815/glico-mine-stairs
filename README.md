# 地雷格力高 · 双人联机与人机对战

游戏大厅提供「双人联机」和「人机对战」。两种模式共用阶梯、埋雷界面和回合规则。

[观看规则与实战演示（普通话旁白，约 2 分钟，3.73 MB）](docs/gameplay-guide.mp4)

## 运行

双击 index.html 即可离线进行人机对战。电脑对手凛会提前选好自己的雷位和手势。在同一标签页刷新或返回大厅后，可以继续已提交的对局。

联机服务需要 Node.js 18 或更高版本，不需要 npm install。

在项目目录运行 `npm start`，然后在浏览器打开 `http://localhost:8787`。

- 同一网络：双击“启动联机版.cmd”。双方打开窗口中显示的同一个局域网网址。
- 跨网络：在 .tools/cloudflared.exe 已就绪后，双击“启动公网联机.cmd”。等待终端打印 https://…trycloudflare.com，并打开该网址。
- 公网网址同时保存为“公网游戏地址.txt”。它是临时网址，需要这台电脑和服务持续运行；重启隧道会生成新网址。长期固定网址需要部署到持续运行的 Node.js 主机。

一方输入昵称创建房间，将邀请链接或 6 位邀请码发给另一方。另一方打开同一游戏网址并加入。两人到齐后，各自选择三个不同台阶；提交前可双击已选台阶或雷位卡片取消。选满三颗后点击“确认提交地雷”，双方均确认后开始猜拳。双方提交手势后同时揭晓。每轮只允许胜者移动。对局结束后需双方同意才能再开一局。

## 已实现规则

- 起点 0、终点 46；最先到达终点者获最终胜利。
- 双方各埋 3 颗地雷，1–45 级均可选，每级一颗。重合位置公布，仅重选重合的雷。
- 拳获胜前进 3 级，剪刀或布获胜前进 6 级。平局不移动；非平局会清零连续平局计数。
- 连续平局 5 次，当前位置更靠近终点者赢得该轮；同级时先到达当前台阶者赢。仅该轮胜者可选前进 3 或 6 级，之后继续猜拳。
- 踩到自己的雷时公开雷位，玩家停在该级，地雷保留。对手踩中时消耗这颗雷，并后退 10 级，最多退到起点。每次回退都检查落点，可以连踩多颗对手的雷。旧版存档中仍在棋盘上的地雷从恢复时起按此规则结算。
- 规则未定义的“同级且同时到达”保留待裁定状态，不自动新增判胜规则。

## 同步与数据

联机时由服务器判定胜负、移动和触雷。只向玩家返回自己的完整雷位及对手已暴露的雷位；待揭晓手势不发送给对手。身份凭证保存在当前浏览器标签的 sessionStorage 中，刷新可恢复，关闭标签后可能无法找回该席位。双方短时断线不自动判负。房间存档在 .runtime/rooms.json；请勿公开或分享该文件。服务器只提供游戏页面、游戏脚本和明确的 API，不提供目录浏览。24 小时未有操作的房间可能被清理。

## 检查

运行 `npm test`。

覆盖秘密埋雷、重复位置重选、锁定手势、回合移动、连续平局及起点例外、到达顺序、一次性地雷和连锁回退、接口认证、重复请求、双方重开、两个独立 HTTP 客户端和存档恢复。

双方共用的规则位于 rules.cjs，联机服务及身份验证位于 server.mjs 和 game-core.mjs，页面交互与电脑对手位于 online.js。
